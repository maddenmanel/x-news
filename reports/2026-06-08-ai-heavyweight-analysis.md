**关键帖**：

- 背景延续：SK Hynix 与 NVIDIA 的多年内存技术合作仍在被广泛讨论（Vera Rubin 等平台）。

**为什么重量级**：
这些不是孤立的合作伙伴关系，而是 NVIDIA 系统性构建“AI 工厂”生态的实操动作。覆盖国家主权云（SK Telecom）、大型财阀的机器人+云+数据中心（LG）、physical AI 与电源/材料基础设施（Doosan），加上之前的内存伙伴，形成了从硅到工厂到应用的全栈绑定。
Jensen 通过 Bloomberg 表态“全球科技股回调是买入机会，AI 的建设才刚刚开始”，直接为这些动作定了调。

**影响洞察**：
- 对韩国/亚洲：加速主权 AI 和工业 AI 能力建设，降低对单一云厂商依赖。
- 对全球竞争：进一步抬高其他 AI 芯片/云玩家的进入门槛，NVIDIA 在 physical AI（机器人、具身）+ 云基础设施的护城河在快速加宽。
- 对模型训练/推理成本：更多 AI 工厂上线将直接影响下一波更大模型的可用算力供给曲线。

**信号强度**：极高。多条官方账号 + 新闻源确认，集中在同一天，属于典型的“基础设施军备赛”连续剧最新一集。

### 2. 中国 AI 模型在 OpenRouter 使用份额实现结构性反超（持续验证中）

**关键帖**：@RnaudBertrand 再次强调（并附图）中国模型已在 OpenRouter（最大 AI API 聚合平台）上完全超越美国竞品。

驱动因素明确指向 2026 年发布的模型：
- Kimi K2.5（1 月）
- MiniMax M2.5（2 月）
- DeepSeek V4（4 月，最常被提及的 tipping point）

优势总结（帖中直接列出）：
- 价格至少低 10 倍
- 大多数任务达到美国模型 90% 以上水平
- 开源 + 可自托管 / ZDR，隐私与数据控制显著更好

线程讨论进一步强化了“agent 使用场景下 token 消耗极高，价格敏感度大幅上升”的现实，许多用户表示在实际 agent 工作流中“付 10 倍价格是 stupidity tax”。

**为什么重量级**：
这不是基准小胜，而是真实开发者钱包投票后的市场份额数据（OpenRouter 流量/使用量）。线程中关于“intelligence index” vs “实际 token volume 使用”的辩论，进一步澄清了“使用量主导”的现实。

**影响洞察**：
- 对开发者/企业（尤其是中国用户）：切换或多模型路由的 ROI 极其清晰。大量 agent 类应用（token 重度）会天然偏好中国模型。
- 对美国 frontier lab：定价压力和“足够好就行”门槛正在快速形成。除非在特定垂直或最前沿能力上建立不可替代的代差，否则高端份额会继续受到挤压。
- 对开源生态：中国模型的开源属性正在转化为实际采用飞轮。

**信号强度**：高。图表 + 具体模型时间线 + 多轮讨论，属于可追踪的宏观趋势。

### 3. OpenAI 在 Codex 重度用户实验上推进产品闭环

**关键帖**：@sama 转发 OpenAI 员工关于“Codex 大按钮”实验的帖，实验计划在未来 100 天每天挑选一名“impressive or incredibly useful work”用户，给予 1 个月 10x 用量限制，并评论 “interesting recursive loop here maybe”。

**为什么重量级**：
这不是简单的营销，而是 OpenAI 在 coding/agent 产品方向上的真实用户反馈飞轮尝试。通过极端重度使用来发现新能力边界、收集数据、迭代产品。Sam 的评论暗示这可能形成自我强化的循环（优秀用户产出更好案例 → 更多优秀用户被选中 → 数据飞轮加速）。

**影响洞察**：
- 展示 OpenAI 当前重点仍在把前沿模型能力产品化为“让更多人/团队能高效构建应用”的方向。
- 与中国模型的“低价够用”路径形成鲜明对比：一方在打性价比+开源规模，一方在打闭环实验+垂直深度。
- 对竞争对手的启发：类似的重度用户计划可能成为 agentic coding 工具的标准打法。

### 2.1 基础设施与 AI 工厂军备竞赛进入实操密集期
今天的核心增量新闻全部指向“AI factory”的物理落地：国家/企业级云、机器人+电源+材料、内存栈。NVIDIA 正在把“AI 工厂是下一场工业革命引擎”从口号变成一个又一个具体项目。这对 2027 年及以后的模型 scaling 能力有直接的供给侧影响。

OpenRouter 数据 + agent 场景下的 token 经济现实，让“10x 贵只是 stupidity tax”的观点从吐槽变成了可观察的行为。2026 年上半年中国模型的集中发布正在产生复利效应。

### 2.3 产品化路径分化明显
- OpenAI：通过重度用户实验快速迭代 agent/coding 产品闭环。
- NVIDIA 生态：把模型能力锚定在物理世界和大规模工厂。

这种分化比单纯的“谁的模型参数更大”更有长期意义。
