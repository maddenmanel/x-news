# AI 重量级动态报告

本目录存放每日使用 x-news 系统生成的 AI 重量级观察与深度分析文章。

## 文件命名
- `YYYY-MM-DD-ai-heavyweight-analysis.md`

## 如何生成
1. 在项目根目录运行：
   ```powershell
   pwsh scripts/daily.ps1
   # 或指定日期
   pwsh scripts/daily.ps1 -Date 2026-06-07
   ```
2. 复制生成的完整提示，粘贴给 Grok（当前这个支持原生 X 搜索工具的 Grok 最佳）。
3. Grok 会调用工具抓取 + 按照 prompts/analysis-prompt-zh.md 的模板输出文章，并建议保存到本目录。

## 报告价值
- 聚焦“重量级”而非噪音：只关注核心实验室、创始人、高信号基础设施、突破性研究。
- 提供聚类 + 趋势洞察 + 对中国产业/构建者的启示。
- 可作为每日/每周 AI 情报输入，用于投资、产品、研究方向决策。
